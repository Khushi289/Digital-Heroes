Task B — Website Performance Diagnosis

## Overview
Performance analysis and optimization of a real publicly accessible website with poor mobile performance.
The task focused on identifying performance bottlenecks, understanding their root causes, prioritizing fixes by impact and implementation cost, and rebuilding one section to demonstrate measurable improvement.


## Work Completed
Full mobile performance diagnosis
Field and lab performance analysis
Identified specific bottlenecks and their causes
Prioritized fixes based on impact vs. implementation cost
Rebuilt one page section as an optimized standalone demo
Compared before and after performance metrics
Prepared a non-technical client-facing summary


## Deliverables
TASK B.pdf — Complete diagnosis report, recommendations, evidence, metrics, and client summary
index.html — Standalone optimized section demo
