Task A — PagePulse Website

## Project Overview
PagePulse is a fictional B2B website monitoring and website quality platform created as part of the Digital Heroes Web Development assignment.
The goal of this project was to build a clean, responsive, accessible, and professional multi-page marketing website using hand-written HTML and CSS.

## Pages Included
The website contains four main pages:

Home — Introduction to PagePulse, its purpose, key benefits, and primary call-to-action.
Product — Overview of PagePulse features and how the product helps teams monitor and improve website quality.
Pricing — Pricing plans and feature comparison for different types of users.
Contact — Contact information and a form for users who want to get in touch with the PagePulse team.
